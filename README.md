## 📖 项目简介

智慧校园信息管理平台是一个基于 Java EE Web 技术构建的综合性后台管理系统。本项目主要解决校园内部复杂的数据管理需求，通过对用户、角色、专业、班级及学生信息的统一维护，提升校园行政与教务管理的信息化水平。

本项目采用经典的 MVC 架构，高度模块化，代码结构清晰，是典型的 Java Web 企业级后台应用。

## 🛠️ 技术栈

- **后端架构**：Java EE (JSP, Servlet, JavaBean, DAO 模式)
- **数据库**：MySQL
- **前端技术**：HTML5, CSS3, JavaScript, 框架式页面布局 (Frame/Iframe)
- **服务器与开发工具**：Apache Tomcat, Eclipse IDE
- **设计模式**：MVC

## ✨ 核心功能模块

### 1. 多角色分类导航
- 系统打破了传统的单一菜单模式，按**系统中心、教师中心、学生处、行政部门**进行分类。
- 基于 RBAC 权限模型，不同角色登录后台后，系统会自动渲染出不同的功能菜单树，实现精准的权限隔离。

### 2. 基础数据管理
- **专业与班级管理**：支持专业信息的增删改查、班级设置、师资力量展示及培养方案的录入。
- **用户信息管理**：系统用户的统一开户、信息修改、密码重置及状态（启用/禁用）控制。

### 3. 学生信息综合管理
- 将学生个人基本信息、历次考试成绩与在校成长历程整合在同一视图下。
- 支持对学生数据进行多条件联合检索、统计、跟踪与历史数据维护。

## 🎨 交互与 UI 设计
- **分级折叠菜单**：后台采用动态折叠式侧边栏菜单，支持主菜单与子菜单的展开收起，主内容区域采用 Iframe 框架嵌入，保证页面切换时左侧导航不闪烁，提升用户体验。
- **框架式布局**：统一的顶部 Logo、当前登录用户信息展示、退出登录入口，保证后台系统的一致性。

## 🚀 快速开始

1. 确保本地安装 JDK 1.8+ 及 Tomcat 8+。
2. 部署 MySQL 数据库，导入项目附带的 `.sql` 文件。
3. 在 **Eclipse IDE** 中导入项目，配置 `ConnDB` 中的数据库连接参数。
4. 添加 MySQL 驱动至 Build Path 或 `WEB-INF/lib` 目录。
5. 启动 Tomcat 服务器，在浏览器访问系统登录页。
